Your first program

Every C++ program starts in the main function.

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, world!";
    return 0;
}

Variables and input

A variable stores a value. Each one has a type.

int age = 18;          // whole number
double price = 9.99;   // decimal number
string name = "Aziz";  // text (needs #include <string>)

cin >> age;            // read from the keyboard
cout << name << " " << age;
A double cannot hold text. Use string for names.

Loops

A loop repeats code. This one prints the numbers 1 to 5.

for (int i = 1; i <= 5; i++) {
    cout << i << endl;
}

Functions

A function is a reusable block of code.

int add(int a, int b) {
    return a + b;
}

int main() {
    cout << add(1, 5);  
}

Tips for beginners

1. Every statement ends with a semicolon ;

2. You cannot declare two variables with the same name in one scope.

3. Give variables a value before you use them.

4. Read compiler errors from the top: the first error is usually the real one.
