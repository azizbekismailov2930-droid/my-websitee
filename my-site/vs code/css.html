CSS functions, one at a time

A function in CSS looks like name(value). It takes a value in, does a small job, and gives a value back. Each part below shows what the function does, the code, and the live result.

var() calc() rgb() / hsl() clamp() linear-gradient() rotate() / scale()

var()

Reads a custom property (a value you named yourself, starting with --). Change the value in one place and everything that uses it updates.

.box {
  --brand: #2f6bff;
  --radius: 12px;
  background: var(--brand);
  border-radius: var(--radius);
}
.box.second {
  --brand: #e63946;   /* only this line changes the color */
}

Result: same rule, different --brand

First box uses --brand blue
Second box overrides --brand to red

calc()

Does math with mixed units. Here: take the full width, subtract a fixed sidebar and the gap.

.side { width: 120px; }
.main {
  width: calc(100% - 120px - 12px);
}

Result: resize the window, the blue part keeps filling the rest

120px
100% - 120px - 12px

rgb() and hsl()

rgb(red, green, blue) uses numbers 0 to 255. hsl(hue, saturation, lightness) is easier to tweak: hue is the color on a 0 to 360 wheel, lightness makes it lighter or darker. A slash adds transparency.

.sw1 { background: rgb(255, 99, 71); }
.sw2 { background: hsl(210, 80%, 50%); }
.sw3 { background: hsl(210, 80%, 30%); }  /* same color, darker */
.sw4 { background: rgb(47 107 255 / 40%); } /* 40% opaque */

Result

rgb
hsl 50%
hsl 30%
40% alpha

clamp()

Takes three values: minimum, preferred, maximum. The result grows with the screen but never goes below the minimum or above the maximum.

h1 {
  font-size: clamp(1rem, 4vw, 2.2rem);
  /*               min   grows  max   */
}

Result: resize the window and watch this text

I grow and stop.

linear-gradient()

Makes a smooth blend between colors. The first value is the direction (90deg = left to right), then the colors.

.grad {
  height: 90px;
  background: linear-gradient(90deg, #2f6bff, #ffb703);
}

Result

rotate(), scale(), translateX()

Used inside transform. They turn, resize, or move an element without changing the layout around it.

.rot { transform: rotate(20deg); }
.sc  { transform: scale(1.3); }       /* 30% bigger */
.mv  { transform: translateX(20px); } /* 20px to the right */

Result
